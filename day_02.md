/bin: binaries. Contains essential, low-level command-line tools and foundational excutables. Required for the OS to function.
+ Includes key commands like pwd, ls, cd, mv, cp, rm,...
/etc: editable text config. Configuration files for the system to run.
/Volumes: acts as a mounting point for external connection (USB,...)
/Users: stores all individual accounts and their personal data.
/System: stores the essential core files the OS requires to function.
/tmp: temporary storage location to hold data like caches, crash logs, installation files.
/usr: contains read-only user utilities, application libraries, and developer tools.
/var: stores variable and transient data created bt OS and running apps -> consistently changing.

which vs find:
- which finds the excutable binaries or scripts.
- find finds the files or directories
