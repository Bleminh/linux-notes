# System Monitoring:
`uptime`: How long the system has been running
`df -h`: Checking disk space in a human-readable format
`free - m` (or `top -l 1` for macOS): Checking RAM usage
`echo` with formatting (`\n`)
`ps aux`: Lists all the processes. `head -n 6` grabs the top 6 lines (1 header + next 5 lines)
